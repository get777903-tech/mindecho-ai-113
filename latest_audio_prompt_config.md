# 📜 ФАЙЛ 1: ИССЛЕДОВАНИЕ ПРИЧИН УСКОРЕНИЯ И НАСТРОЙКИ СИНТЕЗА

## 🔍 ИССЛЕДОВАНИЕ В ИСТОЧНИКАХ И ПРИЧИНА УСКОРЕНИЯ В ELEVENLABS:
1. **Жесткое ограничение ElevenLabs API по скорости**:
   * Минимальный порог параметра `speed` равен **`0.70`**. При значении ниже `0.70` ElevenLabs выдает ошибку валидации HTTP 400.
2. **Анализ интонационного ускорения первых фраз**:
   * Без специальных знаков препинания короткие первые предложения артикулируются нейросетью с ускорением, так как алгоритм считает их второстепенными вводными фразами.
   * Как только встречалась фраза со словами *"тебя очень сильно любят"*, алгоритм делал глубокий выдох и замедлялся.
3. **Решение (как достигнуто одинаково медленное звучание с 1-го слова)**:
   * Вставлены **длинные тире (`—`)**, **запятые (`,`)** и **многоточия (`...`)** перед паузами `<break time="3.5s"/>`.
   * Тире и запятые принудительно заставляют модель ElevenLabs снижать тон, протягивать гласные звуки и произносить каждое слово первой фразы **ОДИНАКОВО МЕДЛЕННО И ГИПНОТИЧЕСКИ С 1-ГО СЛОВА**.
